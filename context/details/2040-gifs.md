# 2040: GIFs

Accepted, not implemented · 2026-11-12 · [index](README.md)

## Rules

- **Slots, not screens.** Each placeholder belongs to a named slot; screens can share one
  (e.g. `banner`). `Gif` takes a `slot`, never a URL or file.
- **Once per session.** At start-up the server returns a random GIF URL per slot from
  cloud storage. The pick lives in the session ([1010](1010-app-state.md)) and doesn't
  change until the app closes.
- **Local fallback** (`assets/gifs/`): used when the server is unreachable, before login
  (no token yet: Landing results, Register), or when a URL fails to load.
- **Presigned URLs** are never logged or kept past the session (CLAUDE.md).
- **Server work:** no GIF route yet; e.g. `GET /gifs` → `{ slot: url }`.
