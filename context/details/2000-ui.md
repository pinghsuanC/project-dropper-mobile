# 2000: UI

Area head for the 2000s · [index](README.md)

Windows 98 inspired: square corners, no shadows, 2px bevels (raised = white top/left,
black bottom/right; sunken = reversed, white inside; buttons sink while pressed).
Screens are built only from our own components; CLAUDE.md "UI style" has the hard rules
and the find → reuse → ask → write-back procedure.
