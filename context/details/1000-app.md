# 1000: App

Area head for the 1000s · [index](README.md)

FastAPI server (CLAUDE.md "How the app works"). One user, one PC for now.

## Screen map

```
Server config (no device_id, no Cloudflare values, or Cloudflare refused) ──→ Landing

Landing ──┬─ success ──────────────→ Home (paired / unpaired)
          ├─ failed ───────────────→ Register ──→ Home – unpaired
          └─ server unreachable ──→ Retry → Landing

Home – unpaired ──→ Pairing 1 (camera note → camera) ──→ Pairing 2 ──→ Home – paired
Home – paired ──┬─ View server files ──→ Server status
                ├─ Upload? Yes ────────→ Upload
                └─ Properties (taskbar)
Share menu ──→ Shared file – loading ──┬─ ready ──────────────→ Shared file to PC
                                       └─ not ready / timeout → error → Landing
```

| Section | Screens and states |
|---|---|
| Landing | Terminal; success; failed; server unreachable |
| Register | Register; errors: server unreachable, server error (code + details) |
| Home | Unpaired; paired (Checking… → View server files); paired – server error |
| Pairing | Step 1; camera note; camera; step 1 error; step 2; step 2 error |
| Server | Server status – empty; – files |
| Upload | Start; in progress; partial failed; file too large; success |
| Sharing | Loading (times out into the error); Shared file to PC; error ("Process Aborted", details say why) |
| Device & User | Properties (paired); Properties (not paired: Unknown / N/A) |
